# 海豚干饭冲滩（Dolphin Hunt）

一款基于 **Vite + TypeScript + 原生 HTML5 Canvas 2D + Web Audio API** 的俯视角海岸线物理小游戏（Idea Lab v2 — Project 04）。  
玩家扮演一只贪吃海豚：趁涨潮冲上浅滩狂咬逃命鱼，在退潮变干沙前扭回深海回满湿润度；真搁浅了还有戴草帽的热心路人把你推回海里（每局限 3 颗救援心）！

## 核心玩法

- **动态潮汐与 4 层地表物理**：周期 `4.5s` 的正弦潮汐线 `tideY(x, t)` 动态切换 `DEEP_WATER`（深水高速+迅速回湿）、`SURF_FOAM`（浪花浅滩）、`WET_SAND`（湿沙中摩擦+慢速失水）与 `DRY_SAND`（干沙高摩擦+快速失水）。
- **3 种逃命鱼 AI & 连吃倍率**：
  - **银小鱼（+20）**：遇海豚惊慌冒 `!` 朝岸上逃窜；
  - **肥金枪仔（+60）**：高分诱饵，专往高处干沙滩蹦；
  - **滑溜飞鱼（+40）**：上岸后还会额外向岸连跳 2 次。
  - `3.5s` 内连续干饭叠加 `×1 -> ×2 -> ×3 干饭狂潮`。
- **热心路人双戏份**：平时在沙滩踱步顺手把高处搁浅的鱼拨回浪边（`路人神助攻！`）；海豚湿润度归零时冲来把你推回深海（`快推一把！`，消耗 1 颗心）。

## 操作方式

- **触屏 / 鼠标**：按住主画布拖动引导海豚游动（引导点自动上偏 `36px` 防手指遮挡）；点击右下角独立圆形按钮「冲滩猛扑」触发加速突进；右上角切换静音。
- **键盘**：`WASD` 或方向键游动，`Space` 冲滩猛扑，`R` / `Enter` 结算页一键重开。
- **调试视图**：URL 后追加 `?debug=1` 可查看动态潮汐湿沙边界、海豚嘴部咬合圆、鱼群惊慌警戒圈与 AI 状态、路人位置与救援心。

## 目录结构

- `src/config/tuning.ts`：视口 `390×640`、固定步长 `1000/60`、潮汐周期与振幅、分区摩擦/失水速率、猛扑冷却（`0.75s`）与 3 种猎物参数
- `src/game/rules.ts`：纯 TypeScript 潮汐函数 `computeTideY`、地表分区、湿润度/救援状态机、鱼群惊慌逃窜与连击倍率逻辑
- `src/game/world.ts`：海豚分区物理、猛扑脉冲、鱼群生成与粒子/飘字管理
- `src/game/audio.ts`：Web Audio API 合成音效（破水猛扑、干饭咀嚼、低湿警报、救援与助攻）
- `src/render/painter.ts`：Canvas 2D 分层海滩/浪花泡沫、拟人海豚表情、逃命鱼、草帽路人、HUD 与 `?debug=1` 叠层
- `src/main.ts`：DPR 自适应、多指隔离指针控制、`localStorage` 最高分记录
- `tests/rules.test.ts`：Vitest 单元测试
